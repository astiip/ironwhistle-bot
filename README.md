IRONWHISTLE is a bright daytime railway switcher. Switch the rails, keep the furnace fed, and outrun the Iron Maw across 7 runs. Shunt trains to their stations, shoo off Cinder Imps, Rail Rats and Boiler Brats, chain perfect routes for score, and break the three-phase Iron Maw boss before the furnace hits zero.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
